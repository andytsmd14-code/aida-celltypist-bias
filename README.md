# aida-celltypist-bias

Does the ethnic composition of a single-cell reference atlas affect annotation accuracy for underrepresented populations?

This project uses the **AIDA dataset** (Asian Immune Diversity Atlas, Kock et al., *Cell* 2025) to systematically test how the proportion of Singaporean Chinese donors in a CellTypist reference panel affects annotation accuracy when predicting cell types in Singaporean Chinese query samples.

---

## Background

Most single-cell reference atlases are built predominantly from European-ancestry donors. AIDA provides a uniquely diverse Asian cohort, allowing us to ask whether annotation accuracy improves when the reference better represents the query population.

---

## Experiment Design

- **Query set**: 20 Singaporean Chinese donors (fixed, `seed=42`)
- **Reference set**: 60 donors per run, with Singaporean Chinese proportion swept from 0% to 100% in 10% steps
- **Repeats**: 36 independent runs per proportion
- **Tool**: CellTypist (logistic regression), trained on 2,000 highly variable genes
- **Metric**: Macro-F1, per-cell-type F1/precision/recall

---

## Notebooks

| Notebook | Description |
|---|---|
| `aida_sg_chinese_full_curve.ipynb` | Main experiment: macro-F1 dose-response curve across all proportions and cell types |
| `aida_bcell.ipynb` | Follow-up: why B cell F1 decreases with more SG_Chinese reference (annotation artifact) |
| `aida_nk_other_significant.ipynb` | Follow-up: NK cell, double negative T regulatory cell, and innate lymphoid cell annotation quality |

---

## Key Findings

- Overall macro-F1 increases slightly but consistently as SG_Chinese reference proportion increases (0.811 → 0.822)
- **Natural killer cells**, **innate lymphoid cells**, and **double negative T regulatory cells** show the largest F1 gains
- **B cells** show a paradoxical F1 decrease, explained by the fact that all "B cell" and "NK cell" entries in AIDA's Level-1 annotation are QC-flagged cells — annotation artifacts rather than true biology

## Data

The AIDA dataset (`AIDA.h5ad`) is not included in this repository due to file size.  
Download from: [AIDA CellxGene portal](https://cellxgene.cziscience.com/) or the original publication:

> Kock et al. "Asian Immune Diversity Atlas reveals distinct immune cell distributions across ethnic groups." *Cell* (2025).

Place `AIDA.h5ad` in the same directory as the notebooks before running.

## Output Files

Pre-computed results are included in `output/` so analysis cells can be run without re-training:

| File | Description |
|---|---|
| `results_full_curve.csv` | Macro-F1 for every proportion × repeat combination |
| `all_reports.json` | Full per-cell-type classification report for every run |
| `*.png` | Figures generated by the notebooks |
| `important_celltypes.csv` | Per-run F1 for cell types with |Δ F1| > 0.03 |
